# Esther Lee Qian Hui — portfolio album

A seven-page personal portfolio built for BITM2313 Human-Computer Interaction. Navigate it like a record sleeve: each page is a track, with EcoTech and Nexplore as the featured work.

## Pages

- Album cover and tracklist
- Artist notes: profile, qualities, and HCI design decisions
- Academic history
- EcoTech project
- Nexplore internship
- Selected projects
- Contact details

## Interaction and accessibility

Keyboard-accessible navigation and focus states, skip link, responsive layout, optional color theme, reduced-motion support, and a user-activated synthesized record tone. The tone does not autoplay.

## Preview locally

Open `index.html` in a browser or run a static server from this folder.

## Publish with GitHub Pages

After merging the portfolio branch, open **Settings → Pages** and select **GitHub Actions** as the source. The workflow at `.github/workflows/portfolio-pages.yml` publishes this folder. The live URL will be `https://assumie.github.io/assumie/` after GitHub finishes the deployment.

This portfolio includes contact details intended for public career inquiries.
